# Hashirigaki Lab — Research Portfolio

Public portfolio for independent research in nonlinear dynamics, memory and cognition, collective behavior, and inspectable AI systems.

**Website:** https://hashirigaki.github.io/  
**ORCID:** https://orcid.org/0009-0003-6326-7984  
**Research code:** https://github.com/Hashirigaki

## Contents

- `index.html` — responsive, static portfolio site; no build dependencies.
- `assets/fdr-terrain.png` — FDR v0.5 conceptual simulation terrain; source: [FDR repository](https://github.com/Hashirigaki/fdr-conceptual-simulation).
- `assets/fdr-standard.png` — FDR v0.5 standard final panels; source: [FDR repository](https://github.com/Hashirigaki/fdr-conceptual-simulation).
- `assets/collective-sweep.png` — archived oscillator numerical measurements; source: [Collective Misalignment repository](https://github.com/Hashirigaki/collective-misalignment-dynamics).

This website links only to publicly released research artifacts. The projects have different verification scopes; see each repository for methods, results, limitations and licensing. The portfolio does not imply formal institutional affiliation.

## Publishing

In **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/ (root)**. GitHub Pages will serve `index.html` at the URL above.

Update `index.html` and commit to `main` to publish revisions. Keep contact information and unpublished materials out of this public repository.
